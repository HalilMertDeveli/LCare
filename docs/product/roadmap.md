# Roadmap

| Phase | Theme | Key outcomes |
|---|---|---|
| 0 | Foundation | Monorepo, API + PostgreSQL, Identity, org scoping, web + Flutter shells, first cross-platform service-request workflow, CI |
| 1 | Customer intake | Customer registration, public service-request form, LED screen records, photo/video uploads (private storage), admin ticket dashboard, customer tracking |
| 2 | Communication & quotes | Per-request messaging, quotations, customer approval, e-mail notifications |
| 3 | Payments | iyzico checkout, payment records, receipts |
| 4 | Remote & field operations | AnyDesk ID registry + approvals + session logs, technician assignment, work orders, scheduling, service reports |
| 5 | Notifications & automation | FCM push, reminders, SLA escalation (Hangfire introduced here), maintenance contracts |
| 6 | Reporting & SaaS readiness | Operational reports, tenant onboarding, subscription model |

The detailed Phase 1 backlog is in [phase-1-backlog.md](phase-1-backlog.md).
